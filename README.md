# Temperature Converter - Oasis Infobyte Internship

This project is a simple Temperature Converter web application created as part of my Web Development and Designing Internship at Oasis Infobyte.

## Features

- Convert Celsius to Fahrenheit
- Simple and clean user interface
- Instant result display
- Responsive design using CSS

## Technologies Used

- HTML
- CSS
- JavaScript

## How it works

User enters temperature in Celsius and clicks the Convert button. The application converts it into Fahrenheit using the formula:

Fahrenheit = (Celsius × 9/5) + 32

## Project Structure

- index.html → Main structure
- style.css → Styling
- script.js → Conversion logic
